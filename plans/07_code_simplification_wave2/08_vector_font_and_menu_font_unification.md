# Plan08 — 向量字型與選單 5x7 字型整合

## 定位

在 `State` 表現層中，`add_char_lines_with_source`（`src/state.rs:L14469-14820`，約 350 行）包含了一個完全手寫的向量字符線段生成表，針對 ASCII 'A'..'Z'、'0'..'9' 及各種標點符號手動編寫了幾百個 `push(line)` 坐標點。

與此同時，`src/menu.rs:L4137-4186` 中已經維護了一個極為精簡且完整的 5x7 點陣 ASCII 字型表（每個字元 5 個 `u8` 位元組，僅約 50 行）。

向量線段可以非常簡單地透過讀取 5x7 點陣位元、並在像素有值處輸出微小線段或四邊形的方式統一生產，無須手寫 350 行的繁瑣線段坐標。

預期削減代碼 ~300 行。
