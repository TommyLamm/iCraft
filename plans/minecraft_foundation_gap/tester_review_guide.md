# Plan 01–34 人工 Review 指引

給 tester 用。自動測試（2026-08-13 serial full suite：1571 passed / 0 failed / 6 ignored）已經覆蓋 headless 與真 TCP harness；**這份文件只寫人眼、手、視窗、音效與 Host+Join 要看的東西。**

不要把「和 Java 1.21.5 每一格都一樣」當通過標準。本路線的完成定義是基礎閉環可玩、權威不複製／不丟物、三種拓撲行為一致。已知差異見 [17_known_differences.md](17_known_differences.md)。

---

## 1. 開始前

### 1.1 啟動

在 repo 根目錄：

```text
cargo run --release
```

獨立伺服器（無視窗）：

```text
cargo run --release --bin icraft-server -- --world saves/review_dedicated --port 25565 --difficulty normal
```

伺服器參數見 `icraft-server --help`。Ctrl-C 會 flush 存檔。

建兩個測試世界，名稱建議：

| 世界 | 用途 |
| --- | --- |
| `review-survival` | Survival + cheats，走完整資源鏈 |
| `review-creative` | Creative + cheats，快速擺裝置 |

建立世界時打開 **Cheats**，方便 `/gamemode`、`/give`、`/time`、`/tp`。Hardcore 另建一個只用來驗死亡。

### 1.2 三種拓撲

每個「必須多人」的項目至少跑一種網路拓撲；總驗收（第 3 節）三種都要跑。

| 拓撲 | 怎麼開 | Tester 角色 |
| --- | --- | --- |
| Singleplayer | 主選單 → Singleplayer → 選世界 | 一人 |
| Listen（Host + Join） | 機器 A：Multiplayer → Host → 選世界 → 埠（預設即可）。機器 B（或同機第二個 `cargo run --release`）：Multiplayer → Join → `127.0.0.1` + 埠 + 不同 username | A 是 Host，B 是 Client |
| Dedicated | 先開 `icraft-server`，再開兩個 client Join 同一個 IP:port，username 不同 | 兩人都是 remote client |

同一台機器開兩個視窗時，第二個視窗用不同 username。Join 失敗先查防火牆與埠，不要當成玩法 bug。

### 1.3 預設操作

`controls.config` 已不再進版本庫。沒改過按鍵時：

| 操作 | 預設 |
| --- | --- |
| 移動 / 跳 / 衝刺 / 潛行 | WASD / Space / Left Ctrl / Left Shift |
| 破壞、攻擊、UI 左鍵 | 滑鼠左鍵（按住挖掘） |
| 放置、使用、開門、開箱、進食、拉弓、舉盾 | 滑鼠右鍵（按住蓄力／進食／格擋） |
| 快捷欄 | 1–9、滾輪 |
| 背包 / 工作站 | E |
| Creative 物品目錄 | Creative 下開背包（E），左側目錄左鍵拿一組、右鍵拿 1 個 |
| 丟出 | Q |
| 主手 ↔ 副手 | F |
| 聊天 / 指令 | T，指令以 `/` 開頭 |
| 暫停 | Esc |
| 除錯疊層 | F3 |
| 視角 | F5 |
| 循環遊戲模式（需 cheats / operator） | G，順序 Creative → Survival → Adventure → Spectator |

常用指令（需 cheats 或 operator）：`/help`、`/gamemode`、`/difficulty`、`/gamerule`、`/time set night`、`/weather`、`/tp`、`/give`、`/kill`、`/spawnpoint`、`/setworldspawn`、`/locate`、`/seed`、`/save-all`。未授權的 Join Client 打管理指令必須被拒絕且世界不變。

### 1.4 怎麼記結果

每一條寫：

```text
日期：
拓撲：Singleplayer / Listen / Dedicated
平台：Windows + 解析度 + 縮放
世界 / seed：
結果：PASS / FAIL / BLOCKED
重現步驟：
預期：
實際：
截圖或短片：
```

**FAIL** = 可重現的功能錯（丟物、複製、Client 自己結算、崩潰、UI 錯到不能操作）。  
**不要當 FAIL**：缺原版變體、箱子蓋沒平滑轉動、沒有煙囪粒子、資源包不能進世界後熱重載 GPU 圖集、headless 已通過但文件寫明不做的完整 vanilla 表。

## 3. 四條端到端（優先）

這四條通過，比勾完 34 個計劃標題更有用。每一條在 **Singleplayer 必做**；標了「網路」的再在 Listen 或 Dedicated 做一次。

### 3.1 生存第一夜閉環（Plan 01–05）

1. 新 Survival 世界出生。確認不是卡在固定 `(8,80,8)` 的虛空或石頭裡。
2. 空手或用工具砍木頭，E 打開 2×2／工作台合成木鎬 → 石鎬。
3. 挖 Cobblestone、Coal、Iron Ore。確認 **不能** 在合成格把礦石直接變成錠。
4. 合成並放置熔爐。放入礦石 + 燃料，看火焰與箭頭進度。關 UI、走開再回來，進度還在。
5. 取出鐵錠，得到 XP。再放一批，確認 XP 不會把上一批再發一次。
6. 合成鐵鎬。放置單箱，把多餘資源放進去。存檔退出再進，箱子內容一致。
7. 合成床，晚上睡覺跳到早上；白天右鍵床只設重生點、不跳夜。
8. 鋤 Dirt/Grass 成農田，旁邊放水，種種子，骨粉催熟，收割，熔爐烤肉／麵包，按住右鍵吃完。飢餓全滿時普通食物不應開吃。

**通過：** 全程不靠 Creative 刷 survivor 鏈；物品 count 與附魔／名稱不消失。  
**網路加測：** Host 熔煉時 Client 看得到進度；兩人同時挖同一作物只掉一次。

### 3.2 死亡與重生（Plan 04、15 Hardcore）

1. Survival 裝滿幾格有耐久／名稱的物品，`/kill` 或跳崖。
2. 死亡點出現掉落物與 XP 球，背包清空（`keepInventory` 預設關）。
3. 重生在床邊或世界出生點，不是固定假座標。
4. 走回死亡點撿回，metadata 還在。
5. 掉落物在區塊保持載入時約 5 分鐘消失；若先卸載再載入，不應立刻重置或複製計時。
6. 另建 Hardcore 世界，死一次：不能再以 Survival 進這個世界；只能 Spectator 或回標題。

**網路加測：** Client 死、Host 活著時時間不卡住；Client 重連後物品以伺服器為準。

### 3.3 進度：要塞 → Nether → End（Plan 10、32）

1. `/locate` 或終界之眼找 Stronghold，不是舊的固定房間。
2. 點燃 Nether portal，走進傳送。重連後仍在 Nether。
2b. 在 Nether 找 Fortress 走廊、Blaze 標記、Nether Wart。
3. 收集眼睛填 End portal，進入 End。
4. 打龍（可用指令輔助，但傳送與完成必須是進門／攻擊，不是編輯存檔）。
5. 確認出口噴泉、龍蛋、End Gateway。Gateway 可往返。
6. 到 End City 開箱子拿戰利品（含 Elytra 路徑）。同一箱子不要開出兩份。
7. 存檔重開，傳送門與維度仍在。

**網路加測：** 只有走進門的人傳送；旁邊觀察者不被一起拉走，也看不到對方私有 session。

### 3.4 社會與自動化（Plan 12–14、28）

1. 找到程序化村莊（不是空殼）。與 Farmer / Librarian 等用綠寶石交易，升級後出現新 offer。
2. 加床後村民可繁殖；床不夠時不繁殖。
3. 若能觸發襲擊：帶 Bad Omen 進村，守完一波，確認勝利折扣或失敗／離開的收尾不會卡世界。
4. 擺 Chest → Hopper → Furnace → Hopper → Chest，物品與燃料總量守恆。紅石充能時 Hopper 停。
5. Comparator 對空／半滿／滿箱輸出不同強度。
6. Dispenser 對箭／桶／打火石有對應行為；Dropper 只吐物品。持續供電只在上升沿射一次。

**網路加測：** 兩人同時看同一個自動化容器，格子不倒退、不複製。

## 4. 各計劃：加了什麼、怎麼測

每一節：**功能**（人看得到的）→ **怎麼測** → **通過** → **不要當成缺點**。

### Plan 01 — Block Entity 與權威變更

**功能：** 箱子／熔爐／告示牌等方塊可以帶持久資料；放置／破壞走同一筆交易（光照、支撐、紅石、存檔、同步一起提交）。

**怎麼測：** 放置箱子與告示牌，寫字，存檔重開。把箱子換成石頭，資料必須消失。Join Client 重連後仍看得到同一個箱子內容與告示牌文字。

**通過：** 重開／重連不丟 BE；換成不相容方塊後資料不幽靈殘留。  
**不要當成缺點：** 本計劃本身只做承載層；完整箱子 UI 在 02。

### Plan 02 — 箱子

**功能：** 27 格單箱、相鄰合成 54 格雙箱、禁止三連、拆一半另一半變回單箱並保留自己的 27 格。左／右鍵、合併、交換。上方被實心方塊擋住不能開。破壞掉落全部內容（含 metadata）。多人同看一箱，每次點擊由 host 結算。

**怎麼測：**

1. 放兩個相鄰箱，開 UI 應為 6×9。第三個相鄰放置必須失敗。
2. 拆掉一半，另一半變單箱，自己的物品還在。
3. 箱頂放實心方塊，右鍵不應打開。
4. 箱內放附魔／改名物品，破壞後撿回，附魔與名稱還在。Creative 破壞也要掉內容。
5. Listen：Host 與 Client 同時開同一箱，交錯點同一格，總數不增加也不消失。

**通過：** 守恆、雙箱規則、擋住不開、多人不同步亂改。  
**不要當成缺點：** 箱子蓋沒有平滑轉動（Plan 26 只做開／關二值姿勢 + 開關音效）。

### Plan 03 — 熔爐與配方

**功能：** 熔爐三格（原料／燃料／產物）、燃料時間、燒煉進度、取出產物給 XP。鐵／金礦不能在合成台變成錠。麵包是三個小麥。有最小 Recipe Book。

**怎麼測：** 煤與木板燃燒時間可分辨。燒鐵、金、沙→玻璃、生肉→熟肉。輸出格不能放東西。輸出滿或沒燃料時不消耗輸入。關 UI、換 Chunk、存檔、重連後進度還在。

**通過：** 生存鏈「木鎬→石鎬→鐵礦→熔煉→鐵鎬」可完成。  
**不要當成缺點：** 沒有完整原版配方書動畫。

### Plan 04 — 死亡、床、出生點

**功能：** 死亡掉落完整 ItemStack；掉落物在載入區約 5 分鐘消失；XP 球。世界出生點安全搜尋。床兩格、面向、夜間睡眠、白天只設重生點、附近有怪不能睡、所有在線同 Overworld 玩家都睡才跳夜。

**怎麼測：** 見 3.2。另測：床跨 Chunk 放置／拆掉必須整張床一起生或一起沒。拆床後再死，應回到世界出生點。兩人 Listen：一人睡、一人醒，不應跳夜；第二人斷線應退出投票，時間不卡死。

**通過：** 掉落守恆、重生合理、睡眠投票不卡。  
**不要當成缺點：** 沒有幻翼實體（`do_insomnia` 目前只擋夜間敵對生成）。

### Plan 05 — 耕作與進食

**功能：** 鋤、農田濕度 0–7、小麥／胡蘿蔔 0–7、水源 4 格灌溉、踩踏退化、骨粉、按住進食。Random tick 有界且可重現。

**怎麼測：** 見 3.1 步驟 8。另測：農田上方蓋實心方塊會乾／退化；沒水的農田偏乾；沒成熟就挖掉落不同；飢餓滿不能開吃；進食中切快捷欄或打開 UI 應取消且不扣食物。

**通過：** 新 Survival 世界能走完「鋤→水→種→等／骨粉→收→煮→吃」。

### Plan 06 — 建築形狀

**功能：** 通用碰撞／選取形狀。橡木／圓石半磚（下／上／雙）、樓梯、柵欄與柵欄門、圓石牆、玻璃片、梯子、站立／壁掛告示牌（可編輯、有長度上限）。

**怎麼測：**

1. 站在下半磚與樓梯上，不要沉進方塊。
2. 不能從柵欄空檔穿過去；玻璃片薄碰撞正確。
3. 梯子可靠、拆支撐梯子掉。
4. 告示牌能寫字、存檔還在；超長字被截斷，不崩潰。
5. 柵欄／牆跨 Chunk 放置後會連上；卸載再載入連接仍對。
6. 半磚旁邊看光照，不應在磚內部出現整面錯黑。

**通過：** 站、走、爬、連、字，四件事都對。  
**不要當成缺點：** 水浸半磚的玩法在 Plan 27，不在 06 第一次交付。

### Plan 07 — 戰鬥、副手、盾、弓

**功能：** 副手格。攻擊冷卻（沒充滿傷害／擊退較弱）。盾牌按住格擋前方。斧可暫時禁用盾。弓需蓄力，太短不射。箭先消耗副手再背包。Leather／Gold／Diamond 護甲。

**怎麼測：**

1. F 把盾換到副手，按住右鍵面對殭屍，正面應擋、背後不擋。
2. 連點左鍵打，傷害應低於等冷卻滿再打。
3. 拉弓：點一下放開不應出箭；拉滿再放，箭速／傷害明顯較高。拉弓中切欄應取消且不耗箭。
4. 副手放箭、主手弓，射完副手箭先少。
5. 穿齊套鑽石甲，同一隻怪打你，傷害低於裸裝。
6. Listen：同一下攻擊不要結算兩次、不要扣兩次耐久。

**通過：** 冷卻、格擋、蓄力、副手消耗、多人不雙擊。

### Plan 08 — 世界高度 -64..319

**功能：** Overworld 高度改為 -64 到 319。舊 0–255 存檔映射上來，負 Y 與 256+ 是新空間，不重刷玩家改過的區塊。

**怎麼測：** 挖到深板岩／負 Y 礦層可站、可放、可存。飛到 Y=300 附近仍能放方塊。開一個遷移前的舊世界（若有），0–255 的建築還在，下面多出來的是新空間不是被覆蓋。F3 看 Y。Host/Client 在負 Y 同時改同一格，重連一致。

**通過：** 負 Y 與頂層不崩、不裂面、不漏光、舊建築還在。

### Plan 09 — 地形與自然模擬

**功能：** 約 16 種可辨識 biome（平原、森林、樺木、針葉、雪原、沙漠、莽原、沼澤、叢林、惡地、草甸、風蝕丘陵、河、灘、海、深海）。連續氣候、河／岸、洞穴、含水層、按 Y 的礦。草蔓延、樹葉凋落、樹苗、仙人掌／甘蔗、掉落沙、火、雪／冰。

**怎麼測：** 同一個 seed 開兩次，遠景地貌應能對上。沿著河走多個 Chunk，河床連續、海邊不要整片漏成牆。沙漠熱、雪原冷，天氣與地表對得上。挖到洞穴入口與深層礦。點火會有限蔓延，雨會滅；沙子失去支撐會掉，不要一次吞掉整根柱子卡死。

**通過：** 能辨識不同 biome、河／岸合理、自然 tick 不爆炸。  
**不要當成缺點：** 不是完整 1.21.5 biome 目錄。

### Plan 10 — 結構、戰利品、維度進度

**功能：** 跨 Chunk 結構（地牢、礦坑、村莊佈局、要塞、要塞傳送門、Nether Fortress、End City）。Loot table 第一次打開才 roll。終界之眼／`locate` 找最近合法要塞。重生錨可在 Nether 設個人重生點。龍死後 Gateway。

**怎麼測：** 見 3.3。另：同一結構箱存檔再開不要重 roll。Host 與 Client 同時開同一結構箱只產生一份 loot。已探索舊區升級後不應突然長出新建築蓋住玩家房子。

**通過：** 結構可找、戰利品不複製、生存鏈能進 Nether／End。

### Plan 11 — 生態與寵物

**功能：** 生成分類與容量。代表生物：蜘蛛、史萊姆（分裂）、女巫、溺屍、惡魂、岩漿怪、凋靈骷髏、狼、貓、馬、蝙蝠、至少一種水生。狼／貓可馴、坐下、跟隨；馬可馴（騎乘在 13）。Peaceful 清敵對。

**怎麼測：** Survival 夜晚看敵對生成，Peaceful（`/difficulty peaceful`）後敵對消失。馴狼：骨頭，坐下／跟隨，存檔重開主人還在。史萊姆打死會分裂。惡魂火球、女巫丟藥看得到即可。遠距未命名敵對會消失；已馴養不應無故 despawn。

**通過：** 生成／難度／寵物存檔說得通。  
**不要當成缺點：** 不是全生物圖鑑。

### Plan 12 — 村莊、交易、襲擊

**功能：** 床／工作站 POI。職業：無業、農夫、圖書管理員、盔甲匠、牧師。綠寶石交易、升級、每日補貨上限。繁殖、農夫收割補種、鐵傀儡。掠奪者襲擊與 Hero 折扣。

**怎麼測：** 見 3.4。另：拆掉工作站，尚未鎖定職業的村民可轉職；已交易過的應留下職業。兩人同時買村民最後一個庫存，只能一人成功。`mobGriefing false` 時農夫不應破壞農田作物。

**通過：** 交易守恆、繁殖有床限制、襲擊能開始也能結束。

### Plan 13 — 船、礦車、馬、地圖、釣魚

**功能：** 船（駕駛 + 一名乘客）。鐵軌／動力軌／感測軌／觸發軌與礦車。已馴馬裝鞍、蓄力跳。羅盤指世界出生點；時鐘顯示 Overworld 時間；地圖探索著色。釣竿：甩竿、等待、咬鉤、收線，loot 分魚／垃圾／寶。

**怎麼測：**

1. 水面放船，開上去劃，第二人可坐副座。船毀／人死／斷線必須下來，不留幽靈乘客。
2. 鋪含轉彎與斜坡的軌道跨一個 Chunk 邊界，礦車能過；沒載入的前方應安全停，不要掉出軌道世界。
3. 動力軌加速／剎車看得到；感測軌能點亮紅石。
4. 馴馬 → 鞍 → 騎 → 蓄力跳 → 存檔再騎。
5. 羅盤指向出生點；到 Nether 時鐘／羅盤可表現不穩定，不要 crash。
6. 釣魚：太早收線應落空；成功有物品且竿掉耐久；取消不應白得戰利品。

**通過：** 騎乘無環、軌道跨 Chunk 安全、釣魚取消／成功分明。  
**不要當成缺點：** 沒有箱船、箱礦車、漏斗礦車。

### Plan 14 + 28 — 紅石容器自動化

**功能：** Hopper 5 格、面朝、冷卻、充能停用。Comparator 讀真實容器滿度。Observer 看前方變化脈衝一次。Dispenser 9 格：箭、噴濺藥水、桶、打火石有專用行為，其餘當掉落。Dropper 只吐出或餵前方容器。上升沿觸發一次。

**怎麼測：** 見 3.4。另：拆掉目的地 Chunk（走遠卸載）時 Hopper 不得抽走來源物品。Observer 不要對著自己的輸出震盪。存檔重開後漏斗冷卻與發射器內容還在。

**通過：** 自動熔煉鏈守恆、上升沿一次、卸載不吞物。  
**Listen 必做：** 兩人同時開著熔爐／漏斗 UI，格子與進度不倒退。這是 Plan 14 仍標未勾的實機項。

### Plan 15 — 模式、規則、指令、建世界

**功能：** Adventure（預設不能改方塊，除非物品有 can_break／can_place_on）、Spectator（穿牆飛、不碰撞、不撿、不開箱）、Hardcore。World rules：`keepInventory`、`mobGriefing`、`doMobSpawning`、`doDaylightCycle`、`doWeatherCycle`、`doFireTick`、`doInsomnia`、`sleepingPercentage`、`pvp`。建世界：模式、Hardcore、難度、seed、是否生成結構、獎勵箱、cheats、Default／Superflat。世界列表可刪／備份。

**怎麼測：**

1. G 或 `/gamemode` 切五種（Hardcore 是世界旗標，不是第五個平常模式）。
2. Adventure：普通手不能挖；Spectator：穿地、打不到、開不了箱。
3. `/gamerule keepInventory true` 後死亡物品還在身上。
4. `/gamerule doDaylightCycle false` 後時間停。
5. Superflat 與 Default 用同一 seed 各建一次，地形明顯不同；關掉 generate structures 後不應再看到要塞／村莊。
6. Join Client 沒有 op 時 `/give` 必須失敗。
7. 刪世界有確認；路徑不能逃出 `saves/`。

**通過：** 政策表跟指令權限正確。  
**Listen 必做：** Host 改 gamerule，Client 看得到且不能私自改。

### Plan 16 + 18 + 21 + 23 + 24 — 多人權威與獨立伺服器

**功能（人看得到的）：** 單人／Listen／Dedicated 共用同一套權威。Join Client 不再本地挖礦結算。獨立進程 `icraft-server` 無視窗可跑。每人一份背包／生命／維度。重連載入自己的資料。重複登入同一身份應拒絕。興趣範圍外的人看不到不該看的容器內容。

**怎麼測：**

1. Dedicated 開起來，兩個 client 進去，各自走遠，確認對方區塊與實體大致按視野出現／消失。
2. Client A 開門／開箱，Client B 在旁邊應看到門與箱內容變化；B 在 sufficently 遠時不應收到 A 的私有 session。
3. 踢掉 A 再進，位置、背包、維度還在。
4. 第二個視窗用 **同一個 username** 進，應被拒，且不複製一份背包。
5. 伺服器 Ctrl-C 後再啟動，世界與玩家檔還在。
6. Host 暫停／忙時，Client 亂連點不應自己把方塊挖掉（等 server ACK）。

**通過：** 權威在 server；重連不複製；同名拒登。  
**不要當成缺點：** 30 分鐘 GPU 實機 soak、漂亮的伺服器列表視覺，文件標為後續／人工。

### Plan 17 + 19 + 29 — 資源包、語言、無障礙

**功能：** `resourcepacks/` 目錄或 ZIP（要有 `pack.json`）。英／德。選單與 HUD 穩定字串走翻譯。UI 縮放、聊天縮放／透明度、字幕、高對比、減少閃爍、鍵盤導覽（Tab／Shift+Tab／Enter／Esc）。

**怎麼測：** 沿用 [17_qa_checklist.md](17_qa_checklist.md)，重點：

1. 沒有 `resourcepacks/` 也能進選單、建世界、有內建貼圖／音效／英文。
2. 加一個合法目錄包與一個 ZIP，在 Resource Packs 開關、排序、套用。
3. 惡意 ZIP（`../`、絕對路徑、過大）必須拒絕且不落地解壓。
4. 選單切 English ↔ German，HUD、死亡、指令回饋仍可讀；重開遊戲語言還在。
5. 只按鍵盤走完每個選單畫面，焦點環看得到。
6. UI scale 0.75 與 2.0、至少一個寬螢幕與一個 4:3，按鈕不要疊到不能按。
7. 字幕開：受傷／方塊／雷，有方向且佇列不會無限長。減少閃爍時閃電／受傷閃白變弱，但傷害數字不變。

**通過：** 選單可用、語言在、壞包進不來、縮放後關鍵按鈕仍可點。  
**不要當成缺點：** 進世界後改包不會熱換 GPU 圖集；不是完整原版 pack 格式；F3／parser help 未全部翻譯。

### Plan 20 — 回歸硬化

**功能：** 負座標結構 loot seed、舊世界 metadata 還原、`mobGriefing` 只禁生物改世界、不凍結 AI。

**怎麼測：** 到世界負 X／Z 開地牢箱兩次（同 seed 新世界）結果應穩定。`/gamerule mobGriefing false` 後苦力怕／農夫不破壞方塊，但怪物仍會走、仍會打人。

### Plan 22 — 權威玩法域

**功能：** 釣魚結算、熔爐／合成／附魔／鐵砧／釀造交易、戰鬥死亡重生，都在 authority 裡原子提交。

**怎麼測：** 附魔台耗等級與 Lapis 必須一起成功或一起失敗。鐵砧改名：等級不夠時物品與經驗都不動。釀造：等固定 tick 完成才能拿瓶；中途拿走材料應停。這些在 Listen 下 Client 不得本地先扣物品再等 server。

### Plan 25 — 難度

**功能：** `server.properties` 只接受 `peaceful|easy|normal|hard`。Peaceful 清場敵對。Easy／Normal／Hard 追擊速度約 0.9／1.0／1.1。`pvp` 獨立，Peaceful 不會偷偷關 PvP。

**怎麼測：** Dedicated 用 `--difficulty peaceful` 進世界，已有敵對應被清掉。改成 hard，同一種近戰怪追得比較快。`/gamerule pvp true` 在 Peaceful 仍應允許玩家互打（若規則開著）。

**不要當成缺點：** 沒有完整原版飢餓傷害表或生成率表。

### Plan 26 — 容器強制關閉與箱子回饋

**功能：** 走遠、換維度、箱子被拆、斷線，容器 UI 必須關。雙箱第一個觀看者打開、最後一個離開關上（二值 `is_open`）。開關各播一次音效。

**怎麼測：** 開著箱子走遠，UI 應被關掉，游標上的物品回到背包或掉地上，且只發生一次。另一人拆你正在看的箱子，你的 UI 要關。聽開關音，連點不應疊一堆音效。

**不要當成缺點：** 沒有平滑蓋子動畫。

### Plan 27 — 半磚含水

**功能：** 橡木／圓石半磚可含水。水桶對半磚是原子裝／抽。水會按 tick 流動，可跨 Chunk。

**怎麼測：** 對下半磚倒水，半磚還在且含水。用空桶收回，得到水桶，半磚變乾。旁邊應能流到鄰格。存檔重開含水狀態還在。不能對花等不該取代的方塊「隔空」把水灌進去。

### Plan 30 — 真 TCP 驗收（人工對照）

**功能：** Listen／Dedicated 上，釣魚、熔爐、2×2 合成、附魔、鐵砧改名、釀造、戰鬥／重生、亂序／過期請求、重連，都走真 socket。

**怎麼測：** 不必重做 harness。用人做：Join Client 合成一次、熔一次、附魔一次、改名一次、釣一次、打一下怪。斷線重連後背包與位置對。連點同一按鈕不要做出兩個結果。

### Plan 31 — 權威挖掘／放置

**功能：** 開始挖／取消／放置是 typed 請求。Survival 要按住看裂紋進度；換手、走遠、對到別的方塊會取消。掉落與 XP 只結算一次。Adventure 沒有 can_place_on 不能放。

**怎麼測：**

1. Survival 挖石頭：按住看到進度，中途鬆開或切欄，方塊應留下。
2. 挖完掉落一次、工具耐久扣一次。
3. Creative 瞬間破，仍只掉該掉的（容器內容見 34）。
4. Listen：Host 看 Client 的裂紋進度；Client 連點同一格不要原地出兩次掉落。
5. 重連時未挖完的進度應重置，不要幽靈進度把方塊挖掉。

### Plan 32 — 傳送與進度完成

**功能：** 點燃／進入傳送門、維度切換、龍死後噴泉／蛋／Gateway、要塞／End City loot，都走玩家請求而不是改記憶體。

**怎麼測：** 見 3.3。另：觀察者站在門旁邊，開門的人傳走，觀察者留下。重連後仍在目標維度。

### Plan 33 — 釣魚生命週期

**功能：** 甩竿後即使 server 自己在 tick 魚鉤，收線仍應成功，不會因為 revision 過期被拒。重複收線不雙倍戰利品。取消收回鉤。

**怎麼測：** Listen 下甩竿，等到咬鉤再收。成功：物品、XP、竿耐久。立刻再送一次同樣動作不應再給一份。走遠或收桿，鉤消失。另一個玩家不應看到你的私有釣魚 session 內容。

### Plan 34 — 拆容器掉內容

**功能：** 拆非空 Chest／Furnace／Hopper／Dispenser／Dropper 時，格子裡的每一堆（count、耐久、附魔、名字）都變成掉落物。方塊掉落 + 內容掉落 + 方塊變成空氣是一次提交。失敗則箱子還在、東西還在裡。雙箱只掉被拆的那一半。

**怎麼測：**

1. 箱子放兩堆不同附魔物品，挖掉，地上應有箱本體掉落 + 那兩堆，箱子 BE 消失。
2. 熔爐三格都放東西再拆，三格都要出來。
3. 雙箱兩邊放不同東西，只拆左邊，右邊格子還在。
4. 存檔重開，已拆的容器不要把舊物品復活進方塊裡（掉落物仍可在地上）。
5. Listen：拆的人與旁邊觀看者都看到同樣的掉落；觀看者看不到拆的人私有 UI。連點／重送不要掉兩次。
